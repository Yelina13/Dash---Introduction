## Installation

1. Repository klonen:

   ```bash
   git clone https://github.com/Yelina13/Dash---Introduction.git
   cd Dash---Introduction
   ```

2. Optional: virtuelle Umgebung erstellen und aktivieren:

   ```bash
   python -m venv venv
   source venv/bin/activate      # Linux/Mac
   venv\Scripts\activate         # Windows
   ```

3. Abhängigkeiten installieren:

   ```bash
   pip install dash pandas plotly
   ```

   Falls eine Datei `requirements.txt` vorhanden ist:

   ```bash
   pip install -r requirements.txt
   ```

## Anwendung starten

```bash
python [dateiname].py
```

Danach ist die Anwendung im Browser unter `http://127.0.0.1:8050/` erreichbar.
